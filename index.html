Politique de Confidentialité (Privacy Policy)

Cette politique explique comment nous traitons les données via l'API TikTok :

  • Données collectées : Nous accédons uniquement aux informations nécessaires à la publication (via les scopes autorisés comme video.upload).
  • Usage : Les données sont utilisées exclusivement pour permettre la publication automatique de vidéos sur votre compte.
  • Partage : Aucune donnée personnelle n'est vendue ou partagée avec des tiers.
  • Conservation : Les jetons d'accès (tokens) sont stockés de manière sécurisée et peuvent être révoqués à tout moment par l'utilisateur via les paramètres TikTok.
